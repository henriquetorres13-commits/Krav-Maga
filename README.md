# Krav Maga – catálogo (app offline)

App de uso pessoal: catálogo de golpes com busca, filtros por faixa e tipo, favoritos e edição.

Este repositório contém **apenas o app**. O conteúdo (texto e fotos) fica fora do repositório:
abra o app e use "Importar dados" com o arquivo `krav-maga-dados.json` (guardado localmente).
Não adicione esse arquivo nem PDFs ao repositório (ver `.gitignore`).
